**Dynamic Enhanced Resource-Aware Load Balancing Algorithm for Cloud Computing.** 

**Abstract:**
Cloud Computing provides the resources (i.e., computation power, storage, operating system, network, and database) as a public utility. The platform, infrastructure and applications in cloud computing provide services on a pay-as-you-go model and the heterogeneous computing resources are available as a virtualized host. The load balancing is vital to gain higher resource utilization, lower makespan and higher throughput. The static scheduling algorithms usually produce low resource utilization and high makespan, while need all the required information initially. Alternately, the dynamic scheduling algorithms allocate the jobs to computing machines at run-time for better resource utilization and load-balancing to incorporate a dynamic resource pool. The existing dynamic algorithms can lead to increased overhead, requiring continuous system monitoring, job requirement assessments and real-time allocation decisions. This additional computational load has the potential to impact system performance and responsiveness. In this paper, a Dynamic Enhanced Resource-Aware Load Balancing Algorithm (DE-RALBA) is proposed that mitigates the problem of load-imbalance in the cloud computing environment. The proposed DE-RALBA schedules the jobs on the virtual machines (VMs) at runtime using a resource-aware mechanism by maintaining the VMs and job-status tables. The simulation-based assessments are performed using the diûerent instances of GoCJ (Hussain and Aleem, 2018) and HSCP (from Braun et al. , 2000) datasets. The outcomes have revealed that the DE-RALBA mitigates the load imbalance and provides a substantial improvement against existing PSSLB (Alaei and Saû-Esfahani, 2018, PSSELB (Alaei and Saû-Esfahani, 2018 , Dynamic MaxMin (Mao et al., 2014), and DRALBA (Nabi et al., 2021) algorithms in terms of makespan and resource utilization.
